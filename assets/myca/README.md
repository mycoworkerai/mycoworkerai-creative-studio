# Myca Asset Library

**Status: DRAFT**

Canonical home for Myca character artwork and reusable character assets.

Suggested organization:
- `2d/`: approved 2D character artwork, poses, expressions, transparent PNGs.
- `3d/`: approved 3D/game-character renders and turnarounds.
- `source/`: original high-resolution source artwork when appropriate.

Rules:
- Preserve the approved character design; do not redraw the character as SVG or CSS.
- Keep original files intact. Add derivatives as separate files.
- Record provenance, version, dimensions, transparency, and approval status in an adjacent README or asset manifest.
- Do not add generated or unreviewed images as approved assets.
